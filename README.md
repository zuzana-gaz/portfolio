# Library Audit Tool

A Python-based command-line application focused on Object-Oriented Programming (OOP) principles and file handling. This project serves as a practical demonstration of my algorithmic thinking, problem-solving abilities, and clean code practices.

## Origin and Context (AI-Assisted Learning)
This project was developed as an independent assignment during my intensive preparation for the final advanced programming exam at the University of Helsinki (Advanced Course in Programming).

- The Role of AI: I used AI tools to generate the initial assignment specifications, business logic constraints, and edge-case testing scenarios.
- My Work: I designed the entire class architecture, data processing logic, error handling, and coded the application completely on my own from scratch without generating code. This workflow simulates the daily routine of a modern software engineer working in an AI-assisted development environment.

## Concepts and Technologies Used
- Python 3 (pure logic using built-in features without external dependencies)
- Object-Oriented Programming (OOP): Data encapsulation using private attributes and @property decorators; clear separation of concerns into dedicated classes (Book, FileHandler, Library, App).
- Functional Programming: Efficient data filtering and transformation using filter(), reduce(), and lambda expressions.
- I/O Operations and Persistence: Reading and writing text files, robust error handling with try-except blocks (e.g., FileNotFoundError), and maintaining historical statistics across application restarts.

## Repository Structure
- library_project.py - The main source code of the application.
- books.txt - Sample data file containing books to test the application's functionality.
- audit_stats.txt - A file generated by the application to store persistent historical statistics.

## How to Run the Project
1. Clone this repository or download library_project.py and books.txt into the same directory.
2. Open your terminal in that directory and run the following command:
   ```bash
   python library_project.py
   ```
3. Select option 1 from the menu and enter the filename books.txt. You can then explore the other features, such as searching by genre or calculating total borrowings.
